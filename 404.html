📱 How to Install on Mobile Phone (Android)

Follow any of the three simple methods below to install and run FrontCraft PRO on your physical Android device:

1

Method 1: Direct Download on Mobile (Recommended)

Open this page on your Android phone browser (e.g. Chrome). Tap the Download APK button above. When downloaded, tap the notification or open your Files / Downloads folder, click FrontCraftPRO-v1.1.apk, and tap Install. If prompted, allow "Install unknown apps" from Chrome.

2

Method 2: Install via USB Cable (ADB or File Transfer)

Connect your Android phone to your PC/laptop with a USB cable:
• File Transfer: Copy app-debug.apk to your phone's Download folder and open it on your phone to install.
• Developer ADB: Enable Developer Options → USB Debugging on your phone, then run in your terminal:

adb install -r app-debug.apk
3

Method 3: Via AI Studio Settings Menu

Inside Google AI Studio, open the Settings menu at top right and choose "Export APK" or export the project repository to GitHub to obtain the latest compiled APK build artifacts directly.
