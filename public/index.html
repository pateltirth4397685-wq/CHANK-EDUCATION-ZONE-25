FrontCraft PRO

Comprehensive Coaching Class Management System for students, teachers, batches, daily attendance, fee ledgers, examinations, and administrative CSV reporting.

Institutional Management Hub

This repository hosts the source code for the FrontCraft PRO Android application. If you accessed this URL via GitHub Pages, this landing page resolves the GitHub Pages static root requirement (404 File Not Found) and provides quick access to project documentation and build instructions.

👥

Student Management & ID Cards

Register students, assign batches, manage parent contacts, track tuition balances, and generate digital ID cards with verifiable barcodes.

📅

Daily Attendance Tracking

Mark batch roll calls by selected date (Present, Absent, Late, Leave), add custom faculty remarks, and persist to Room database tables.

📝

Exams & Merit Scoreboards

Schedule unit tests, enter marks with live grade badges (A+, A, B, C, D, F), generate merit order rankings, and historical student transcripts.

💳

Fee Invoices & Reminders

Track payments, calculate pending balances, log receipts, and broadcast automated tuition reminders to WhatsApp/SMS.

📊

Administrative CSV Exports

Export Room database student directories and daily attendance registers into sanitized, shareable CSV files protected against formula injection.

🔒

Room Database Persistence

Structured on-device SQLite storage with reactive Kotlin Flow DAOs, foreign keys, and audit logging.

Building & Running the Android App

To build the native Android APK locally on your machine or in Android Studio:

# 1. Clone this repository git clone https://github.com/<your-org>/<your-repo>.git cd frontcraft-pro # 2. Build the Debug APK using Gradle ./gradlew assembleDebug # 3. Locate the compiled APK at: app/build/outputs/apk/debug/app-debug.apk

For live interactive testing, open this project directly in Google AI Studio to run inside the cloud streaming Android emulator.
